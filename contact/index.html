Email us

The fastest way to reach the developer is email:

contact@shiftraw.com

What to include

  • File won't convert? Tell us your camera model, the file extension, and the error message shown on the file card — that's usually enough to reproduce it.
  • Missing a format? Name the extension and the camera that produces it. LibRaw supports more than 20 RAW families, and the list can grow.
  • Feature ideas are welcome — especially ones that make batch workflows faster.

Response time

This is an independent, single-developer project. Most emails get a reply within a few days. "Your converter saved my deadline" emails get read first, as earned.
