ShiftRaw가 다른 이유

대부분의 온라인 변환기는 사진을 서버에 업로드하고, 배치 크기를 제한하고, 워터마크를 찍습니다 — 또는 세 가지 전부. 이곳은 다릅니다.

진정한 프라이버시

디코딩은 WebAssembly를 통해 CPU에서 실행됩니다. 사진이 기기를 떠나지 않습니다 — 페이지가 로드되면 오프라인에서도 작동합니다.

제한 없음, 대기열 없음

무제한 파일, 무제한 변환, 일일 할당량 없음, 파일 크기 페이월 없음. 하드웨어가 유일한 한계입니다.

최대 해상도

센서가 캡처한 모든 픽셀을 LibRaw 엔진과 카메라에 기록된 화이트밸런스로 처리합니다.

워터마크 없음

깨끗한 출력 파일. 무료는 무료라는 뜻 — "모서리에 로고가 박힌 무료"가 아닙니다.

사용 방법

설치 없음, 계정 없음, 업로드 없음. 세 단계, 약 10초.

1

파일 놓기

RAW, HEIC, WebP 파일을 원하는 조합으로 변환기에 드래그 — 메모리 카드, iPhone 내보내기, 다운로드 폴더에서 바로.

2

출력 선택

범용 공유는 JPG, 무손실 복사본은 PNG, 가장 작은 웹용 파일은 WebP. 원한다면 품질도 조절하세요.

3

다운로드

파일을 개별적으로 받거나 모두 다운로드를 누르세요. 아무것도 업로드되지 않았고, 저장되지 않았고, 분석되지 않았습니다.

자주 묻는 질문

내 사진이 정말 업로드되지 않나요?
정말입니다. 변환 엔진은 WebAssembly로 브라우저에 다운로드되어 CPU에서 실행됩니다. 네트워크 탭을 확인하거나 페이지 로드 후 인터넷을 끊어도 — 변환은 계속 작동합니다. 서버 구성 요소, 저장소, 파일 분석이 없습니다.
어떤 RAW 형식이 지원되나요?
CR2, CR3, CRW (Canon), NEF, NRW (Nikon), ARW, SRF, SR2 (Sony), DNG (Adobe/Leica/Pentax/DJI), RAF (Fujifilm), RW2 (Panasonic), ORF (Olympus/OM System), PEF, PTX (Pentax), 3FR, FFF, IIQ, MRW, X3F, KDC, DCR, ERF, MEF, MOS 등 — 총 20개 이상의 확장자를 LibRaw로 디코딩합니다.
파일 크기나 일일 제한이 있나요?
없습니다. 파일은 기기에서 하나씩 처리되므로 실질적인 한계는 기기의 메모리입니다 — 100MP 중형 포맷 RAW도 최신 컴퓨터라면 문제없이 디코딩됩니다. 전달할 서버 비용이 없으므로 할당량도 없습니다.
어떻게 무료인가요? 뭐 숨은 게 있나요?
숨은 것 없습니다: 기기가 작업을 수행하므로 회수할 서버 처리 비용이 없습니다. 사이트는 눈에 띄지 않는 광고로 운영됩니다. 계정 없음, 워터마크 없음, 좋은 설정을 감추는 프리미엄 등급도 없습니다.
모바일에서 작동하나요?
네, 최신 모바일 브라우저라면 어디서든. 큰 RAW 파일(40MP 이상)은 스마트폰에서 느리고 모바일 메모리를 소진할 수 있습니다 — 큰 배치에는 데스크톱이 편하지만, HEIC와 WebP 변환은 자기 사진을 변환하는 iPhone을 포함해 모든 휴대폰에서 빠르게 동작합니다.
품질이 Lightroom 내보내기만큼 좋나요?
단순 변환의 경우, 그렇습니다 — 동일한 오픈소스 LibRaw 엔진이 카메라에 기록된 화이트밸런스로 파일을 처리합니다. 이 도구가 하지 않는 것은 현상입니다: Lightroom 편집은 카탈로그에 있고 RAW 파일에 있지 않습니다. 편집 전 원본에는 ShiftRaw를, 현상된 내보내기에는 Lightroom을 사용하세요.

RAW 파일로 가득한 폴더가 있으신가요?

여기에 놓으세요. 무료, 무제한, 프라이빗 — 변환기가 가져야 할 모습.
