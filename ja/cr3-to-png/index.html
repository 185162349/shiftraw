なぜCR3をPNGに変換するのか？

CR3はキヤノンの現行RAWフォーマットで、2018年にEOS M50とともに導入され、それ以降のすべてのEOS Rシリーズミラーレスカメラが使用しています — R5、R6、R7、R50、R100など。古いTIFFベースのCR2をモダンなISO Base Media File Formatコンテナ（MP4と同じファミリー）に置き換え、キヤノンのより小さいC-RAW圧縮バリアントを可能にしました。

EOS Rボディで撮影しているなら、すでにこの摩擦を知っているでしょう：R5のフルサイズCR3は45メガピクセルで約45 MBあり、AdobeアプリやキヤノンのDPPはCR3をうまく扱えますが、多くのウェブサイト、チャットアプリ、顧客ポータル、古いラップトップは単純に拒否します。

ShiftRawでのCR3からPNGへの変換は完全にブラウザ内で行われます — デコードはWebAssembly版LibRawが実行し、カメラのホワイトバランスが自動適用され、フル解像度の写真があなたのマシンから出ることはありません。

ベストな用途： PNGはロスレスです — 変換された画像のすべてのピクセルが正確に保持され、圧縮アーティファクトもなく、フルのアルファ透明度にも対応しています。代償はサイズです：同等のJPGの3〜10倍のファイルサイズになります。品質を譲れない場合、透明度が必要な場合、最終納品前にさらに編集する場合はPNGを選びましょう。

よくある質問

CR3とC-RAWの違いは何ですか？
C-RAWはCR3ファイル内に格納される圧縮バリアントです。45 MP R5の標準CR3は約45 MB、同じフレームのC-RAWは目立った差なしで約27 MBです。どちらもShiftRawでは同じようにデコードされます — ファイルをドロップして変換するだけ。
LightroomやDPPなしでCR3をJPGに変換できますか？
はい。ShiftRawはWebAssembly版LibRawを使ってブラウザ内でCR3をデコードするため、インストールもサブスクリプションも不要です。Lightroomは現像とカタログ管理のためのツールのままですが、迅速でフル品質のJPG書き出しにはこちらの方が速いです。
CR3ファイルがなぜこんなに大きいのですか？
現代のキヤノンセンサーは24〜45メガピクセルで、RAWは圧縮前にすべてのフォトサイトを14ビット深度で保存します。大きなファイルは編集のレンジの代償です。JPGへの変換は通常、R5のフレームを約45 MBから5〜10 MBに縮め、Web向けのシャープな品質を保ちます。
CR3は廃止される予定ですか？
当面はありません。CR3はEOS RとEOS Mの両ラインでキヤノン唯一の現行RAWフォーマットです。キヤノンは後継を発表していないため、CR3のワークフロー — 納品用のJPG変換を含む — は今後何年も有効です。
PNGが大きなファイルサイズに見合うのはどんなときですか？
ピクセルパーフェクトなロスレスコピー、透明度、または再編集と再保存を予定している場合 — PNGは品質ロスなしでラウンドトリップに耐えます。単純な写真共有には、高品質のJPGが同じ見た目でサイズは数分の一です。
ファイルサイズやバッチの制限はありますか？
ハードリミットはありません。ファイルはデバイス上で1つずつ処理されるため、実質的な上限はデバイスのメモリです — 100メガピクセルの中判RAWは最近のコンピューターで問題なくデコードできます。大きなバッチは順次処理されます。
